# Desain Analisis Algoritma  
## Trip Planner dengan Kahn vs DFS 

Repositori ini berisi implementasi dan analisis **perbandingan algoritma Topological Sort** menggunakan  
**Kahn’s Algorithm** dan **Depth First Search (DFS)** pada kasus **Trip Planner**.

---

## 📌 Studi Kasus
Trip planner disusun berdasarkan:
- Beberapa tempat wisata dikunjungi **dalam satu hari**
- Urutan antar hari **harus terjaga**

## 🚀 Cara Menjalankan `run.ipynb`

Notebook `run.ipynb` merupakan **program utama** dari Trip Planner menggunakan **Kahn’s Algorithm** dan **DFS**.

1. Buka repository GitHub ini
2. Klik file **`run.ipynb`**
3. Klik **Open in Colab**
   - Jika tombol tidak muncul:
     - Buka https://colab.research.google.com
     - Pilih `File` → `Open notebook` → tab `GitHub`
     - Masukkan URL repository
4. Pilih **Runtime → Run all**

!! PENTING UNTUK MENDOWNLOAD `data.json` TERLEBIH DAHULU
